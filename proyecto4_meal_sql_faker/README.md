# Territorios que Dialogan

Proyecto de SQL y generación de datos sintéticos con Faker para simular
el sistema de seguimiento y evaluación de un programa comunitario de
construcción de paz.

## Objetivo

Construir y analizar una base de datos MEAL que permita hacer seguimiento
a actividades, participantes, asistencia, presupuestos, indicadores y
resultados de línea base y medición final en diferentes territorios.

## Tecnologías

- SQL
- Python
- Faker
- Git
- GitHub
